# Linear翻訳の自動復元

公式Linear.appを変更せずに、Mac側の「Linear翻訳補助」が起動時の復元処理を実行します。翻訳は従来どおりLinearの画面内でGPUを使い、本文を外部へ送信しません。

## 現在の検証状況

専用ブラウザで、実行コードと0.8BモデルをIndexedDBへ保存し、ブラウザプロセスを終了・再起動して、ファイル未選択のままGPU翻訳を復元できることを確認しました。

Linear実機でもConsole接続確認、コードとモデルの保存、再起動後の復元を確認しました。起動直後のUI準備を待つ修正版で、補助の起動後にLinearを終了・再起動し、補助側が「実行確認済み」、`lastError` がnullになることを確認しました。利用者による再起動後の動作確認も完了しています。

ログイン時起動は登録済みです。Mac自体の再起動・再ログインによる動作確認は行っていません。

## 初回設定

1. `dist/linear-offline/setup.js` をLinearのDevTools Consoleで実行します。既存の翻訳は一度終了します。未保存なら `linear-offline.js` と `model.gguf` を選びます。コードとモデルの保存が完了してから翻訳を開始します。
2. `~/Applications/Linear翻訳補助.app` を開きます。macOSの「プライバシーとセキュリティ → アクセシビリティ」で、この補助アプリを許可します。
3. Linearを前面にし、画面上部の補助メニューから「接続確認」を実行します。Consoleを使った無害な確認文字列の実行に成功すると、そのLinear版での復元を許可します。
4. 接続確認後、補助メニューで一度「終了」し、リポジトリで `bun run linear:auto-start enable` を実行します。補助を `--watch` 付きで起動するログイン項目を登録します。
5. 作業を保存してLinearを終了・再起動し、Linearを前面にしたまま復元結果を確認します。復元処理中はConsoleへの入力をしないでください。

コードとモデルの保存には、この構成で約610MBの追加ストレージを使います。保存先はLinearオリジンの専用DB `luvpame-linear-offline` です。Guide本文や訳文履歴は保存しません。

## 補助ツールの動作

Linearが背面で起動した場合は、前面になるまで待ちます。フォーカスを奪って起動しません。必要な場合だけDevToolsを一時的に開き、保存済みデータから復元する短いコードをConsoleで実行します。自分が開いたDevToolsだけを閉じます。

起動直後はページの読み込み完了とConsoleの準備を最大30秒待ちます。一時的なアクセシビリティの読み取り失敗は、その期限内で再試行します。コードの実行後は結果の読み取りだけを最大35秒待ち、コードを再送しません。

入力先は、Linearのプロセス内のDevTools Web領域と、空のConsole入力欄を確認できた場合に限定します。Issue欄、Sourcesのコードエディター、別アプリには入力しません。ユーザーがConsoleへ入力中の場合は、上書きせず停止します。

貼り付け時はクリップボードの全形式を一時退避します。途中で別のコピーが行われた場合、その内容を上書きして復元しません。退避できない形式がある場合は操作を停止します。接続確認では実行後に増えたConsole出力を照合しますが、その内容を保存・送信しません。

macOSのフォーカス変更とキー送信は完全には原子化できません。プロセス指定と直前確認で対象を制限しますが、UI自動操作であるため、公式の拡張機能としての動作保証はありません。

## 権限と更新

補助アプリを再ビルドするとコード署名が変わり、macOSの許可を登録し直す必要が生じる場合があります。旧い許可がONでも使えない場合は、補助アプリの項目だけを削除し、`~/Applications/Linear翻訳補助.app` を再追加して許可します。公式Linearや他のアプリの許可は変更しません。

Linearのネイティブ版が更新された場合は、接続確認の再実行が必要です。Consoleの場所や入力欄を確認できない場合も、自動操作を止めます。

## 停止・解除

その回の翻訳だけを止める場合は、Linear内の「翻訳を停止」を押します。次のLinear起動では自動復元します。

ログイン時の自動起動を解除する場合は `bun run linear:auto-start disable` を実行し、補助メニューの「終了」で稼働中の補助も終了します。保存したモデルとコードは保持します。

保存データも消す場合は翻訳を停止した後、LinearのConsoleで `indexedDB.deleteDatabase('luvpame-linear-offline')` を実行します。この翻訳用DBだけを削除します。次回は初期設定が必要です。

## 開発用コマンド

`bun run build:linear-auto-start` でフロントエンドと補助アプリを生成します。`stage` は初回配置、`update` は補助アプリの差し替え、`enable` は接続確認後のログイン時起動登録、`disable` はその解除、`status` は確認です。

CLIの `trusted` はその実行プロセスの許可状態です。ターミナルからの実行とFinderから開いた補助アプリでは権限の責任主体が異なる場合があるため、CLIのtrueだけでGUI補助の許可完了とは判断しません。実際の「接続確認」を判定条件にします。

`status` の `lastStage` は最後の待機段階、`lastError` は最後の停止理由です。段階とエラーは固定の識別子だけを保存し、ページ本文やConsole入力は含めません。
