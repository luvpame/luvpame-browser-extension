# Chrome拡張の統合

複数の拡張が提供する機能を、一つの拡張として利用するための用語を定義する。

## Language

**統合拡張**：今回まとめる機能を一つのインストール単位で提供する Chrome 拡張。
機能ごとに独立してインストールする拡張群とは区別する。

**機能**：統合拡張が提供する、利用者の目的に対応した操作やページ上の動作。
元のリポジトリ一つと機能一つが一致するとは限らない。

**共通メニュー**：統合拡張のアイコンから開く、コピー操作と設定への入口。

**元リポジトリ**：統合する機能のコードが保存されている、移行前の個別リポジトリ。
今回の移行対象外としたリポジトリを含まない。
